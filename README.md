# OpenLess Cloud Sync

独立的开源加密云同步项目，目标是在用户主动开启后，通过同一个 GitHub 账号同步配置、服务 API 密钥和历史文本。数据先在设备内用用户设定的加密密码加密，再上传服务器。

**当前交付：需求与 API 合同，尚无后端实现。** 此目录不包含服务代码、数据库设计、部署方案或架构设计。

从 [文档入口](docs/index.md) 开始。实现者先读需求，再按 HTTP、加密和客户端接口合同开发，不能沿用旧 `/me/sync` 的明文快照格式。

服务代码必须开源；本批没有发布远程仓库，也没有替项目选择或宣称已生效的软件许可证。许可证须在首次代码交付前确认，协议不依赖私有密码学组件。
